Headline project · data migration

Cutover

A fail-closed toolkit for moving a legacy export into a new system: validate against reviewed rules, map columns, reconcile source against target field by field, upload to S3 with hash verification, and sign off with a runbook. It repairs nothing and blocks the handoff on any failure.

34 automated tests · two worked examples (a property-management tenant export, a legacy parts list into a cloud table) · independent code review · byte-for-byte field comparison and SHA-256 checksums

Rules-driven coaching app

Gym Swap

When a planned exercise's equipment is busy or missing, Gym Swap offers a reviewed substitute and explains the tradeoffs. A deterministic rules engine decides; an optional explanation layer only cites reviewed coaching notes, so no model ever invents advice. The first public piece of seeform, a longer project on movement coaching.

133 exercises · 270 reviewed comparisons · 357 automated tests in the source suite · shipped through a Lab-first release process with phone acceptance checks

JavaScript · esbuild · retrieval over reviewed notes · Cloudflare Pages
